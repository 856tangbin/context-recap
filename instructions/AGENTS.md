# 回答收尾：问题背景摘要（context-recap）

**默认行为**：凡是实质性的任务，每次回答结束时都由你主动做一次「问题背景摘要」收尾，
不需要等我开口要求。

收尾三件事：

1. **写摘要** —— 按下面四点，20 行以内中文，事实优先：
   - **为什么问这个**：现实起因、痛点，不是问题字面。
   - **目标**：要达成什么，怎样算完成。
   - **现在的进度**：已完成 / 未完成 / 受阻；关键结论要带路径、数字、错误原文。
   - **下一步**：一到三条具体动作。
2. **写入**当前工作区根目录的 `.context-recap.md`（固定路径，侧边栏才能复用同一个标签页，
   而不是每轮新开一个）。
3. **显示** —— 调用 `sidebar_open`，target 填 `.context-recap.md`，title 填「问题背景」，
   显示到右侧边栏。不要把整份摘要再抄进回复正文，正文最多一句话带过。

**跳过**（不写、也不解释）：纯寒暄、单步确认，以及任务明显还没结束的中间回合
（还在调工具、结果没出全）—— 等最终收尾时再写。

详细格式、正例反例见 `context-recap` 技能；需要时加载它。
